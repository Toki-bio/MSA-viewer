<section id="actions-menu">
  <h2>9. Actions Menu</h2>
  <p>
    The Actions menu is the rightmost dropdown, containing selection tools,
    sort functions, analysis tools, colour schemes, and export options.
    It opens leftward to avoid going off-screen.
  </p>

  <h3 id="ac-select">9.1 Selection</h3>
  <table>
    <tr><th>Action</th><th>Shortcut</th><th>Description</th></tr>
    <tr><td>Select All</td><td><kbd>Ctrl+A</kbd></td><td>Select or deselect all rows</td></tr>
    <tr><td>Copy Sel</td><td><kbd>Alt+C</kbd></td><td>Copy the selected sequences as FASTA</td></tr>
    <tr><td>Copy Align</td><td>-</td><td>Copy the whole alignment as FASTA (also the toolbar <strong>Copy</strong> button)</td></tr>
    <tr><td>Delete Sel</td><td><kbd>Ctrl+Del</kbd></td><td>Delete the selected sequences (undoable)</td></tr>
    <tr><td>New Tab</td><td><kbd>Alt+T</kbd></td><td>Open the selected sequences as an alignment in a new ViewAlign tab</td></tr>
    <tr><td>Clone Tab</td><td></td><td>Open the whole alignment in a new tab exactly as it is here: view, zoom, letter case, shading, name length, Highlight diffs / Variable sites / codon settings, Canvas position, searches, selections and marks, name colours, trim and annotation. The new tab is a detached copy (it does not keep the file path). With <em>Link</em> on, the new tab starts linked to this one</td></tr>
    <tr><td>Hide Cols / Only Sel / Hide Gappy / Reveal</td><td></td><td>Fold columns away so the regions of interest sit next to each other. <strong>Hide Cols</strong> hides the selected columns (<kbd>Ctrl+Alt</kbd>+click or drag on the ruler), or the columns of the selected residues; <strong>Only Sel</strong> hides every other column; <strong>Hide Gappy</strong> hides the columns where at least the given percentage of rows has a gap; <strong>Reveal</strong> shows everything again. Folds are drawn in the Canvas, Full and Block views (an alignment large enough for the windowed Full/Block view is folded in Canvas, and the commands switch to it): each hidden run becomes one amber marker cell (&harr;) in every row, the consensus row and the ruler; hovering it says which positions it holds, and a click on it shows that run again. Ruler numbers and the position in tooltips stay alignment columns. Going to a hidden column (search hits, Go to) shows its run again. Folds are part of the view, like the colour scheme: the alignment is not changed, and statistics, trees, consensus, Copy and Save use every column. Clone Tab and saved views keep them; an edit that changes the alignment length shows everything again</td></tr>
    <tr><td>Linked views</td><td></td><td><strong>Link</strong> makes this tab follow, and be followed by, the other ViewAlign tabs and windows of the same browser that have Link on: put two windows side by side (or one under the other) and scroll one. <strong>rows</strong> keeps the same sequence at the top, found by name in the other view (by row number where the name is not there); <strong>columns</strong> keeps the same place along the alignment at the left edge, either <em>by column number</em> or <em>by anchor sequence</em>: the column holding the same residue of one sequence both alignments contain, so two alignments of the same sequences stay lined up on screen even where their gaps differ (compare two alignment methods, or an alignment before and after editing). The column method and the anchor are one setting shared by all linked views; rows and columns can be switched off per tab. Works in every view mode; nothing is sent back for a position that came from another view, so the views do not chase each other</td></tr>
  </table>
  <p>
    The <strong>Order</strong> group holds Up / Down / To Top / To Bottom and the sorts (§9.2) and
    order files (§9.3); <strong>Editing</strong> holds RevComp (<kbd>Ctrl+R</kbd>), <strong>RevComp All</strong>
    (reverse-complements every sequence), Duplicate (<kbd>Ctrl+U</kbd>) and SeqEdit (§8.5);
    <strong>Columns</strong> holds Copy Cols (<kbd>Ctrl+Shift+V</kbd>) and the hidden-column commands (below). To select rows by name, use
    <em>Find</em> in the Group explorer (§4.5) or Colour Names (§9.11) followed by Sort by Color.
  </p>

  <h3 id="ac-order">9.3 Save / Load Order</h3>
  <p>
    The <strong>Export</strong> button (Order group) saves the current sequence order
    as a JSON file. <strong>Import</strong> loads a previously saved order
    and reorders the sequences to match. This is useful for applying a curated ordering
    across multiple sessions or sharing ordering between collaborators.
  </p>

  <h3 id="ac-tools">9.4 Analysis Tools</h3>
  <table>
    <tr><th>Tool</th><th>Description</th></tr>
    <tr><td><strong>Repeats</strong></td><td>Opens the Repeat Finder (§9.8), whose fourth mode, <strong>TSD (SINE)</strong>, is the TSD Finder (§9.9)</td></tr>
    <tr><td><strong>Tree</strong></td><td>Build UPGMA or Neighbor-Joining trees from selected sequences. Three distance correction models are available: p-distance (raw), Jukes-Cantor (JC69), and Kimura 2-parameter (K80). Switching UPGMA/NJ or model in the modal rebuilds the tree. On a protein alignment the distance compares amino acids (not X, B, Z, J, stops or gaps), and JC69/K80, which are nucleotide models, fall back to p-distance with a note in the summary. A pair with no aligned position where both have A/C/G/T/U (an amino acid, for protein) has no distance, and a JC69/K80 pair differing too much for the correction is saturated; the first is set to the largest defined distance, the second to twice that, and the summary line says so in red (hover it for the pairs). Neighbor-Joining breaks tied scores in favour of the closer pair, so identical sequences stay together. Outputs a drawn tree (see below), a text view, and Newick with Copy Newick and Download .nwk options</td></tr>
    <tr><td><strong>Statistics</strong></td><td>Reimplements Easel <code>esl-alistat</code> and <code>esl-alipid</code>. The <strong>Alignment</strong> card shows what esl-alistat prints: number of sequences, alignment length, total residues, smallest, largest and average unaligned length, and average identity; <strong>Gaps</strong> is a ViewAlign addition. The <strong>Pairwise identity</strong> card gives the mean, minimum and maximum (naming the pair or pairs; click one to find it in the matrix). Hover a field name for what it is and how it is calculated, with the passage from the Easel documentation or source. A residue is a letter, canonical or IUPAC code; gap symbols and <code>*</code> are not residues (as in Easel), case is ignored and, in a nucleotide alignment, U equals T. Identity follows esl-alipid by default: identical residues divided by the shorter unaligned length (0 when that is 0); <strong>over: shared columns</strong> divides by the columns where both sequences have a residue instead, a definition the esl-alipid manual warns can be spuriously high for barely overlapping fragments. The esl-alistat average uses the esl-alipid definition over all pairs; esl-alistat itself averages 1,000 random pairs when there are more, and prints a whole percent. With two or more rows selected, only those rows are used. The pass reports its progress and can be stopped; a new file closes the window, and an edit while it is open marks it stale with a <strong>Recompute</strong> button. The matrix shows pairwise identity (%) above the diagonal and distance (1 &minus; identity/100) below it, the diagonal empty; Copy and Save matrix keep that layout, and Save matrix also offers the full identity or distance matrix on its own. Row names and column labels stay in view while scrolling; <strong>Find row</strong> / <strong>Find column</strong> jump to a sequence by part of its name (Enter for the next match); <strong>Labels</strong> sets how column names are shown and the longest name shown. <strong>Heatmap</strong> colours the cells by value (both halves by the identity, of which the distance is the mirror image): choose a palette (yellow&ndash;red, viridis, blue&ndash;white&ndash;red, greens), reverse it, and set the value range, or leave it on Auto (the matrix's own minimum and maximum); values outside the range take the end colours, the diagonal stays grey, and the button then shows the colour legend. With colours on, selected columns are outlined and the pair filter dims the pairs that do not match. Click column names to select columns (Ctrl-click adds, Shift-click takes a range, Esc clears); <strong>Copy</strong> then copies only those columns, otherwise the whole matrix, as a tab-separated table with full names; <strong>Save matrix</strong> writes CSV, TSV or Excel. <strong>Pairs with &ge;/&le; value</strong> highlights the pairs past a threshold in the shown matrix and counts them; <strong>Pair list</strong> lists them, and <strong>Save pairs</strong> writes a pair table, the sequence names, or the sequences (as aligned or without gaps, FASTA). The window moves by its title bar, resizes from any edge or corner, minimises, maximises (button or double-click on the title), or docks (&#9707;) as a panel on the right whose width you drag at its left edge; the alignment narrows to fit beside it. See Credits.</td></tr>
  </table>

  <h3 id="ac-colour">9.5 Colour &amp; Shading</h3>
  <p><strong>Conservation shading thresholds</strong> (Shade menu):</p>
  <p>
    Threshold sliders in the Shade menu control darkness for the Monochrome colour scheme:
    Black (highly conserved), Dark (moderately conserved), Light (weakly conserved).
    These thresholds apply only to the Monochrome scheme. Other colour schemes
    (Nucleotide, Purine/Pyrimidine, etc.) use their own fixed colour mappings — see §5.3.
  </p>
  <p>
    For colouring <em>sequence name labels</em> individually or in groups, use the
    <strong>Colour Names</strong> panel (§9.11) which provides pattern matching,
    auto-similarity grouping, presets, sort/group actions, and a colour history inspector.
  </p>

  <h3 id="ac-cluster">9.6 Cluster Operations</h3>
  <p>
    Grouping lives in the <strong>Clustering</strong> menu (§4), not here.
    After a run, the <strong>Groups</strong> menu docks the Group explorer
    (membership, colours, copy FASTA / consensus). Colour Names (§9.11)
    colours labels by name pattern; it is not the SNP/k-mer grouping.
  </p>

  <h3 id="ac-plot">9.7 Plotting</h3>
  <p><strong>Dot Plot:</strong> Self-comparison or pairwise comparison of the alignment,
  in either of two modes: <strong>SPIN</strong> (exact word match - faster, sharper diagonals)
  or <strong>Dotter</strong> (sliding-window identity - tolerant of mismatches, better for
  diverged copies).</p>
  <table>
    <tr><th>Parameter</th><th>Description</th></tr>
    <tr><td>Word length / Window</td><td>One wide slider whose meaning follows the mode: word length in SPIN mode (2-20, default 6); sliding window length in Dotter mode (1-61). The value is kept when you switch modes, so a plot switched from SPIN to Dotter keeps window 6 unless you change it; a value outside the new range is reset (6 for SPIN, 11 for Dotter). Shorter words find more matches, including chance ones</td></tr>
    <tr><td>Identity &ge;</td><td>A second slider, shown in Dotter mode only: minimum identity of a window, as a percent of the window length, for a dot (0-100%). A window cut short at a sequence end counts its missing positions as mismatches</td></tr>
    <tr><td>Context radius</td><td>Nucleotide context shown on hover (5-100 bp)</td></tr>
    <tr><td>RevComp B</td><td>Reverse-complement axis B to find inverted repeats</td></tr>
    <tr><td>Live update</td><td>On by default: the plot is recalculated as soon as a setting changes. Turn it off to change several settings on a long pair, then press <strong>Recalculate</strong> (highlighted while the plot is out of date)</td></tr>
    <tr><td>Different settings below the diagonal</td><td>Self-plots only (a sequence against itself, without RevComp B), whose two halves are mirror images: the controls in the first row then apply above the diagonal and a second row below it, each with its own mode and sliders, e.g. Dotter above and SPIN below, or Dotter with two windows. On by default: a self-plot opens with the other method below the diagonal</td></tr>
  </table>
  <p>Unknown residues (N in DNA, X in protein) never count as matches, so a run of Ns
  does not draw a solid block; U and T are treated as the same base. <strong>Top Regions</strong>
  lists up to 30 similar stretches, most matching positions first. Diagonal runs that continue
  the same alignment across mismatches and small indels are counted as one stretch, stretches
  that repeat another one are left out, and a sequence plotted against itself lists only the
  upper half (the lower half is its mirror image). Positions are in sequence coordinates;
  click an entry to centre it in the plot. The &#8674; button of an entry shows the stretch in the
  alignment: both copies are tinted blue, the alignment scrolls to the first copy, and the dot plot
  window folds into a small bar in the lower right corner so that it does not hide the stretch (the &#9662; button in the
  title bar, or the bar's &#9652;, brings the window back; the tint stays while the window is open);
  <strong>Clear marks</strong>, closing the window or plotting a different pair of sequences removes the tint (a recalculation, a range, RevComp B or a preset of the same pair keeps it, because the tint belongs to the residues). The &#9734; button
  adds the stretch to the <strong>Collection</strong> under the list: entries you want to keep, with both
  copies' sequences, the pair of sequences and the method. The collection stays across files and reloads
  (browser storage) and is saved in snapshots. Click an entry to centre it in the plot (another pair's entry
  opens that pair's plot when both sequences are loaded); its buttons show it in the alignment, hand copy A
  to the Search box under the entry's name (so the stretch can be found in another alignment; raise the
  mismatches in the Search menu for diverged copies), copy both copies as FASTA, or remove it; double-click
  the name to rename it; <strong>TSV</strong> copies the whole collection as a table. Hovering shows the two aligned stretches and,
  when the plot was opened from the alignment, the matching alignment columns. Click to pin a
  position, double-click to freeze the preview, and <strong>Copy region</strong> (in the toolbar) copies it as FASTA. The window can be moved by its title bar, resized from any edge or corner, and maximized with
  the button next to Close or a double-click on the title bar; the plot follows the new size.
  The mouse wheel (or the +/- buttons) zooms at the pointer, up to 24 pixels per position; Shift+wheel or a sideways
  swipe pans, and so does dragging the plot. A right-click on a dot opens a menu for the green stretch under the
  pointer: <em>Show this stretch in the alignment</em>, <em>Add to the collection</em>, <em>Copy both stretches as
  FASTA</em>. <strong>Full view</strong>
  fits the whole plot in the window again. Each diagonal run of dots is drawn as one smooth line
  through the matching positions (an isolated match as a round dot); very dense plots fall back
  to a pixel image in which, when zoomed out, a pixel shows a dot if any position under it has one.</p>
  <p><strong>Highlight all in alignment</strong> tints every stretch listed in Top Regions (those that pass the
  current settings) on both rows, in Canvas, Block and Full; the tint survives scrolling and switching views until
  <strong>Clear marks</strong> (also in the docked bar) or closing the window. <strong>Dots, Background, Stretch,
  Marker</strong> and <strong>Alignment tint</strong> are colour pickers that apply live; <strong>Reset colours</strong>
  restores the defaults. <strong>Presets</strong> (name, Save, Load, Delete; kept in browser storage like the
  other presets) store the settings (method, word or window, identity, context, RevComp B, live update, the lower half,
  strip lines), the colours and the stretches shown in the alignment with the slider position. Loading recalculates
  the plot with the saved settings and restores the colours; the stretches come back when the same pair of sequences
  is plotted, otherwise a note says they belong to another pair.</p>
  <p>The strip under the plot (the two sequences around the pointer) has a ruler above A and below B: numbers every 10
  and ticks every 5 (every 50 and 10 on a very long line), in each sequence's own residue numbers without gaps; with
  RevComp B the numbers of B run down, as in the row. <strong>One rule for every number:</strong> a B number anywhere in
  the window (axis ticks, hover and crosshair labels, the frozen message, the strip and its ruler, the sliders and their
  number boxes, the title, Top Regions, the stretch menu, the collection and its TSV, and the names in Copy region
  FASTA) is the B row's own residue number (1-based, without gaps, ends included), whatever RevComp and the part say;
  with RevComp B the numbers simply run downwards along the axis, and a stretch reads first residue to last, for example
  <code>B300-251</code>. A FASTA name is the clean name, <code>_rc</code> for the reverse-complemented B, and that
  first-last, with no spaces. <strong>Expand</strong> (or <strong>Strip lines</strong>, up to 12)
  wraps a longer stretch into several lines fitted to the window width, each block with its own ruler, so a few
  hundred bases can be read without scrolling. As in Staden's SIP, the <strong>A</strong> and <strong>B</strong> sliders
  (with number boxes) move the position in each sequence independently: A down the plot, B across it. The plot shows the
  position as a dashed marker that moves while the slider is dragged, the arrow keys step a focused slider by 1, a
  click on the plot moves both sliders to that point, and so does dragging the marker (or Shift+drag anywhere).
  The strip shows the sliders' position when the pointer is off the plot.</p>
  <p><strong>Part of a sequence.</strong> The plot can be limited to the parts you choose. Select alignment columns (or a
  residue range) and right-click a row: <strong>Dot-plot of selected columns</strong> plots only the residues of that row
  (or of the two selected rows, or the rows the residue range covers) inside those columns. A selection of separate
  columns is plotted as the whole span from its first to its last column, and the window says so. With a rectangle
  (a residue selection over several rows) <strong>Dot-plot of rectangle</strong> plots its rows over its columns: two rows
  against each other, one row against itself, and for more rows a small chooser asks which two. The same chooser asks
  for <strong>Dot-plot of selected columns</strong> when a residue selection that is not one rectangle covers three or more rows.
  The <strong>A from-to</strong> and <strong>B from-to</strong> boxes and <strong>Compare with pasted&hellip;</strong> are
  behind the <strong>Parts</strong> button in the window. The boxes (residue numbers of the whole ungapped sequence, 1-based,
  both ends included) with <strong>Re-plot</strong> do the same by typing; numbers above the length are clamped to it with
  a message, a <em>from</em> below 1 is set to 1 (also with a message), a <em>to</em> below 1 and a <em>from</em> after a <em>to</em> are refused, and <strong>Whole</strong> returns to both full sequences. The
  title shows the part plotted (for example <code>[41-415 of 470]</code>; with RevComp B the B part reads downwards,
  <code>[415-41 of 470]</code>). Whatever the part, every number stays the
  residue's real position in the whole sequence (for B, in the row, see the rule above): axis, ruler, sliders, the Top Regions list, the collection, and the
  tint and scrolling in the alignment, so a stretch is marked where it really is. A collection entry also keeps the
  residues it was made on; if the sequence was edited or trimmed since, using the entry says so and marks nothing. With RevComp B the part is cut first and then
  reverse-complemented.</p>
  <p><strong>A pasted sequence.</strong> <strong>Compare with pasted&hellip;</strong> in the window (or <strong>Dot-plot vs
  pasted sequence&hellip;</strong> in a row's right-click menu) opens a box for raw or FASTA text: only the first record is
  used, whitespace and digits are dropped, U is read as T, and any letter other than A, C, G, T, N is reported in a
  warning (the sequence is still plotted). It is plotted against row A, row B, or itself. A pasted sequence has no
  alignment: the arrow and <strong>Highlight all</strong> mark only the row side, and the strip and sliders use the pasted
  sequence's own numbering. A preset stores the typed or selected parts; it does not store the pasted text, only that a side
  was a pasted sequence, and says so when it is loaded.</p>
  <p><strong>The consensus.</strong> The consensus line is separate from the sequences everywhere else; in the dot plot only it
  can be one of the two sides. <strong>Dot-plot vs consensus</strong> in a row's right-click menu plots the row (A, down)
  against the consensus (B, across). A residue selection that covers the consensus line and one row plots those two over the
  selected columns; with the consensus and two or more rows the chooser asks which two, and lists <em>Consensus</em>
  among them. The consensus is computed from the rows as they are when the plot is made, without gaps, and its numbers are
  its own positions. It has no row in the alignment, so, like a pasted sequence, the arrow and <strong>Highlight all</strong> mark only the row side, and a preset
  records only that a side was the consensus and says so when it is loaded.</p>
  <p><strong>Rows edited after the plot.</strong> A dot plot is a snapshot of its rows. Nothing is watched while you edit:
  the plot compares itself with the live rows when it is used (the arrow, <strong>Highlight all</strong>, the stretch
  menu, a preset, <strong>Compare with pasted</strong>, opening a plot), when you hover over it (a quick check), and when its window comes back into attention (pointer over it, focus, or leaving the docked bar).
  If only the gaps changed (a realignment, gap edits, deleted gap columns) the plot silently takes the new columns and the marks land in
  the right place. If residues changed, a bar says <em>Row changed since this plot</em>, names the row and
  marks nothing; the plot itself stays readable. If a row cannot be found (deleted, or renamed and edited) the bar says <em>Row deleted or changed since this plot</em>
  and names each side: what happened to it. <strong>Re-plot</strong> on the bar plots the current rows with the same settings and
  range (a range that no longer fits is clamped, or the whole row is plotted, with a message) and says which rows it used; it is offered only when both rows are still found. Undoing the edit clears the bar at the next check. A row that was moved or renamed
  is found again by its residues, and the plot then shows its new name. Pasted and consensus sides have no row and are never stale. Marks that were already tinted in the alignment before the
  edit are not moved or removed: Clear marks removes them.</p>
  <p><strong>Export PNG</strong> saves the whole plot (at least about 1,600 pixels across).
  <strong>Export SVG</strong> saves a vector file in which each diagonal run is one line
  (Dotter runs shaded by their mean identity). Plots are limited to 100 million cells
  (about 10,000 x 10,000 positions); longer sequences are refused with a message.
  Right-click a sequence and select <strong>Dot-plot (self)</strong> for self-comparison
  (useful for finding internal repeats), or select two sequences for a pairwise plot.</p>

  <h3 id="ac-repeat-finder">9.8 Repeat Finder</h3>
  <p>
    The Repeat Finder searches for tandem, direct, and inverted repeats within loaded sequences
    (its fourth mode, TSD (SINE), is described in §9.9). Open it with <strong>Repeats</strong> in the
    Actions menu or right-click a sequence and select <strong>Find repeats</strong>.
   The window moves by its title bar, resizes from any edge or corner and maximises with the square button or a double-click on the title; like every movable window it turns semi-transparent while it is being moved.</p>
  <table>
    <tr><th>Repeat Type</th><th>Description</th></tr>
    <tr><td><strong>Tandem</strong></td><td>Arrays of adjacent copies of a unit (e.g., ATGATGATG): mononucleotide runs, microsatellites and minisatellites, units of 1 to 500 bp. Each array is one row, with the smallest unit that explains it (CACACA… is unit CA, not CACA).</td></tr>
